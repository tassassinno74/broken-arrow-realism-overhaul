# Broken Arrow Realism Overhaul

A realism overhaul for the **Broken Arrow** campaign, by tassassinno.

Over 4,500 unit statistics rewritten from real-world data: true weapon ranges,
calibres, armour, optics, sensors and ballistics, on a 1:1 map scale — one metre
in real life is one metre in game. Reworked helicopter flight and countermeasures,
terrain cover that actually protects, and two campaign divisions per side giving
you access to every unit of your faction. Optional cheats, five languages
(English, French, Russian, German, Chinese), and it works with or without DLC.

**Single player only.** This mod is not made for multiplayer and refuses to run
when the game is started with the anti-cheat enabled.

This repository contains the full source code of the mod. Build instructions are
in the source folder.
