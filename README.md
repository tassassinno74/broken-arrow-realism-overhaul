# broken-arrow-realism-overhaul
Realism overhaul for the Broken Arrow campaign. Over 4,500 stats rewritten from real-world data: true ranges, calibres, armour, optics and ballistics at 1:1 map scale. Reworked helicopters, countermeasures and cover. Every unit of your side unlocked in the campaign. Single player only. English, French, Russian, German, Chinese.
